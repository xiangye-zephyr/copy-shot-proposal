# 文案镜头提案台

**让每一句文案，都能找到对应的画面。**

一个用于视频提案展示与讨论的交互页面。以 HOKA FLYRUN 为案例，把 21 段脚本、分镜参考、素材来源和剪辑思路连接起来，让观看者沿着故事理解文案与画面的关系。

## 为什么做这个

脚本在表格里，参考图在文件夹里，剪辑想法散落在备注里。讨论一条视频时，常常需要来回切换，才能说清“这句话为什么这样写、这里准备放什么画面”。

提案台按叙事顺序组织内容，在「文案」与「镜头」两种视角间切换，方便逐段讲解、比较画面选择，也方便回到整体结构。

## 从文字到画面

| 视角 | 展示内容 |
| --- | --- |
| 文案 | 5 个章节、21 段脚本，以及各段的表达结构与创作思路 |
| 镜头 | 主选、备选画面与段落之间的衔接方式 |
| 素材 | 参考图预览、原始来源和画面用途 |
| 总览 | 整体叙事顺序与段落定位 |

支持图片放大、全屏演示，以及段号、进度条和键盘左右键导航。

## 打开项目

在仓库顶部选择 **Code → Download ZIP**，解压后用浏览器打开 `index.html`。请保留文件夹结构，图片与脚本会从相邻文件中加载，无需安装依赖。

先在「文案」模式浏览整体故事，再切换「镜头」逐段查看画面。参考图下方的来源可跳转至原网页，需要联网访问。

## 关于这个案例

页面包含 35 张参考图片；部分镜头以文字示意卡呈现画面位置与用途。脚本中的产品和活动信息对应案例当时的语境。

本项目用于展示视频提案方法，与品牌无隶属关系。第三方图片按页面标注追溯来源，相关权利归原权利人。
