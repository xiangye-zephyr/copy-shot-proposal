# 文案镜头提案台

把一份视频提案拆成可浏览的文案、分镜、素材来源与剪辑提示。通过段落导航和双模式切换，展示从脚本到画面的对应关系。

## 使用

下载仓库后，用浏览器打开 `index.html`。无需安装依赖；查看原始来源需要联网。

- 21 段文案，按 5 个章节组织。
- 切换「文案 / 镜头」，查看结构分析或分镜参考。
- 点击段号、底部进度条或键盘左右键切换。
- 点击图片查看大图，点击来源访问原网页。
